# F-G40. PingFederate と PingOne Advanced Identity Cloud は、`actor_token` を使う RFC 8693 の委任に対応し、後者は `may_act` で代理を限る

PingFederate は、RFC 8693 の交換に対応し、subject のトークンと actor のトークンで、委任と成り代わりを扱う。PingOne Advanced Identity Cloud は、委任に `actor_token` を求め、`may_act` が許さないクライアントや行為者の交換を拒み、出すトークンに `act` を入れる。

DPoP と mTLS の結び付けと、交換との関係は、読んだ範囲に記載がない。
