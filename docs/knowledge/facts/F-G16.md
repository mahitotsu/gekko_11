# F-G16. RFC 9700 は、トークンの宛先を限定し、送信者に結び付けるよう勧める

OAuth 2.0 のセキュリティのベストプラクティスである。権限は、必要な最小限に制限する（§2.3）。トークンは、特定のリソースサーバーに限定する。リソースサーバーは、トークンが自分向けかを検証し、違えば処理を拒否しなければならない（MUST、§2.3、§4.10.2）。トークンは、送信者に結び付ける（mTLS、DPoP。§2.2.1、§4.10.1）。攻撃者がトークンと鍵の両方を入手すると、結び付けの効果は失われる（§4.10.1）。

「token passthrough」と「confused deputy」の語は、読んだ範囲（先頭の約 7 割）に見つからなかった。
