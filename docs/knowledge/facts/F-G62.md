# F-G62. W3C Secure Contexts は、localhost と *.localhost の origin を、名前を必ずループバックへ解決するブラウザに限り、潜在的に信頼できる（安全な文脈になりうる）と扱ってよいとする

§3.1 の手順 4 は、ホストが 127.0.0.0/8 か ::1/128 なら、条件なしに「Potentially Trustworthy」を返す。手順 5 は、ホストが `localhost` か、`.localhost` で終わる名前なら「Potentially Trustworthy」を返す。ただし、ブラウザが let-localhost-be-localhost の名前解決の規則を守る場合だけである。§5.2 は、これを MAY（扱ってもよい）とする。規則の要点は「localhost がループバック以外に解決されないこと」である。

許可であって義務ではないので、どのブラウザで成り立つかは、実機で確かめる（F-G63）。読んだのは編集者草案で、TR の版は読んでいない。
