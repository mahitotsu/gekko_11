# F-G48. SPIRE の agent は、Envoy に SDS で SVID の鍵と証明書を渡せる

SPIRE の agent は、Envoy の SDS の提供者になり、TLS の認証に要る鍵の素材を渡す。Envoy は、agent の UNIX ドメインソケットに向けた cluster を設定する。SPIRE 0.10 以降、SDS は既定で有効である。例では、SAN の照合に `match_typed_subject_alt_names`（URI、SPIFFE ID）を使う。SPIFFE と SPIRE は、認可の土台になる認証を扱い、認可そのものは扱わない。

JWT-SVID は、Envoy が自分で取らない。例では、`ext_authz` を実装する補助のサービスが、agent から JWT-SVID を取ってヘッダーに入れる。
