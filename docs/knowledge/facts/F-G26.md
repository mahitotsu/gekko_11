# F-G26. identity chaining（IETF の草案）は、token exchange と JWT の認可グラントを組み合わせ、信頼の領域をまたいで識別と認可の情報を引き継ぐ

領域 A のクライアントは、自分の認可サーバーから、token exchange（RFC 8693）で JWT の認可グラントを受け取る。それを領域 B の認可サーバーに JWT のアサーション（RFC 7523）として示し、アクセストークンを受け取る（§1、§2.1）。領域の境界をまたぐたびに、同じやり方を繰り返す（Abstract）。

草案である。2026-10-30 の時点で、IESG の承認のあと RFC Editor の待ち行列にあり、提案標準を目指す（datatracker）。RFC の番号はまだない。
