# C-9. INCOSE の要件の書き方の手引きは、実装の詳細を要件に混ぜず、不要な設計の制約を避けるよう勧める

二次資料の要約によると、手引きは、要件に実装の詳細を混ぜること（必要と実装の混同）を問題とし、要件が不要な設計の制約を避けているかを確かめるよう勧める。実現できること（feasible）を、費用、時間、技術、法、倫理、セキュリティの制約の中で受け入れられる危険で実装できること、としている。
