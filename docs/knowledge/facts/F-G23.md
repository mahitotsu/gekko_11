# F-G23. RFC 7515（JWS）は、任意のバイト列に、デジタル署名か MAC で完全性の保護を与える

JWS は、デジタル署名か MAC（Message Authentication Code）で守った内容を、JSON の構造で表す（Abstract）。JWS の暗号の仕組みは、任意のバイト列の完全性を守る（§1）。直列化は 2 つある。コンパクト直列化は、HTTP の Authorization ヘッダーや URI の問い合わせの値のような、狭い場所に向く。JSON 直列化は、同じ内容に複数の署名や MAC を付けられる（§1）。アルゴリズムは別の仕様（JWA）に、暗号化は別の仕様（JWE）にある（Abstract）。
