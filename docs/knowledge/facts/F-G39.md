# F-G39. Authlete は RFC 8693 の交換、DPoP、証明書に結んだトークン、SAN の URI での `tls_client_auth` に対応する

Authlete は、2.3 以降で RFC 8693 の交換に対応し、`actor_token` を受け取る。交換できるクライアントを、秘密を持つものや許したものに限る設定がある。DPoP には 2.2 以降で対応する。証明書に結んだトークンは、クライアント認証と独立に出せる。`tls_client_auth` では、SAN の URI を登録できる。

結び付けたトークンを、別のクライアントが替えたときの扱いは、記載がない。Authlete は認可サーバーの裏側の API で、交換の要求に証明書や proof を渡すかは、組み込む側が決める（推定）。
