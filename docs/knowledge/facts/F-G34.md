# F-G34. RFC 7523 は、署名か MAC をかけた JWT で、クライアントがトークンエンドポイントに自分を示す方法を定める

クライアントは、`client_assertion_type` に `urn:ietf:params:oauth:client-assertion-type:jwt-bearer` を、`client_assertion` に JWT を 1 つ入れて送る（§2.2）。どの種類のトークン要求とも組み合わせられる（§2）。JWT の `iss` と `sub` はクライアント、`aud` は認可サーバー、`exp` は必須である。JWT には、デジタル署名か MAC をかける（§3）。秘密鍵による署名に限らない。`jti` で再利用を防ぐのは任意である（§3、§6）。
