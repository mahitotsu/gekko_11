# F-G57. RFC 9700 と RFC 8705 は、送信者への結び付けの目的を、盗まれたトークンを、鍵を持たない者に使わせないことだとする

RFC 9700 の 2.2.1 は、送信者に結んだトークンを、ある秘密を知ることを示した送信者だけが使えるトークンとする。mTLS（RFC 8705）や DPoP（RFC 9449）での結び付けを、盗まれた・漏れたトークンの悪用を防ぐために使うよう勧める。2.3 は、トークンの宛先を特定の受け手に限るべき（SHOULD）とし、権限の限定は漏れたときの被害を小さくするとする。

RFC 8705 の 1 章は、トークンをクライアントの証明書に結ぶと、権限のない者による盗まれたトークンの使用と再送を防ぐとする。4 章は、公開クライアントの例で、クライアントの実体ごとに自己署名の証明書を作る。

どちらも、正規の鍵を持つ者がトークンを使う場合や、複数の実体が鍵を共有する場合は論じていない。
