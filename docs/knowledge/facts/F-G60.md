# F-G60. Spring Authorization Server の交換は、scope を求めないと、出されたトークンの scope を引き継ぎ、替えを頼む者に登録した scope で照らす

交換の要求に `scope` がなければ、出されたトークンの認可の範囲（scope）を引き継ぎ、替えを頼むクライアントに登録した scope の中にあるかを確かめる。顧客の A は `openid` を含むので、`openid` を登録していない営業 AI エージェントが替えると、`invalid_scope` で拒まれた。

このリポジトリは、交換の要求で `scope=apply` を明示する（token-guard と probe）。
