# F-G52. SPIRE の X.509-SVID は、Subject がサービスによらず同じで、SAN の URI は critical でなく、認証局の証明書を付けずに 1 枚で示される

SPIRE が発行した SVID は、次のとおりだった。
- Subject は `C=US, O=SPIRE` で、どのサービスでも同じ。発行者は、サーバーの設定の `ca_subject` である。
- SAN は URI の 1 つだけ（SPIFFE ID）で、critical ではない。Subject が空でないので、Java の TLS は受け付けた（gekko_07 の、Subject が空の証明書の問題は起きない）。
- 書き出した `svid.pem` は 1 枚で、認証局の証明書は bundle の側にある。

Subject DN でサービスを区別できないので、照合は SAN の URI で行う（D-16、F-G50）。
