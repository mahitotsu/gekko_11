# F-G4. RFC 9449 は、トークンを送信者の鍵に結び付けるが、中身の完全性は守らない

DPoP は、アクセストークンを送信者の公開鍵に結び付け（`cnf` の `jkt`）、秘密鍵を持たない第三者が、盗んだトークンを使えないようにする。proof が対象にするのは HTTP メソッドと URI で、リクエスト本文やヘッダーの完全性は TLS に依存する（§11.7）。クライアントの実行環境を攻撃者が支配すると、オンライン中は proof を作られる（§11.4）。
