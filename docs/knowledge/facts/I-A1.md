# I-A1. 申込みを受けるとき、契約内容の確認を求め、申込書の写しを交付する体制を求める

金融庁の監督指針 II-4-4-2-2 (11) は、申込みを受けるとき、顧客に契約内容の確認を求めることを着眼点に挙げる。申込書の写しや申込内容の書面を顧客に交付する体制も挙げる。非対面の場合の注記では、電話は口頭、郵便は書面、インターネット等は電磁的方法で確認を求め、写しの交付が難しければ、申込み後遅滞なく郵送等で交付する。
