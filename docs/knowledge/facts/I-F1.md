# I-F1. 募集人の適格性の審査、登録、教育・管理・指導、代理店の監査を求める

監督指針は、保険募集人の採用や代理店の委託で、適格性を審査し、審査基準を整備することを求める。特定保険募集人としての登録が要る。法令遵守、商品知識、顧客情報管理について、社内規則に基づいて教育し、指導する。代理店には、無予告訪問を含む監査し、保険料の領収・精算などを管理する。
