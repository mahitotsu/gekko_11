# F-G18. RFC 8707 は、トークンの宛先を、リクエストで指定する仕組みを定める

クライアントが、`resource` パラメータで、トークンを使うリソースを認可サーバーに伝える。認可サーバーは、発行するトークンを、その宛先に限定すべきである（SHOULD）。JWT では `aud` クレームに反映する（§2）。複数の宛先を指定すると、トークンが複数のリソース間で流用されうるので、単一の指定が推奨される（§3）。
