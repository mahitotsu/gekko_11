# I-A4. 紙の書類の改ざん対策として、訂正印、契印・割印、大字がある。捨印は弱点になる

契約書などの一般的な慣行として、次の 4 つが広く知られている。保険の申込書で使われているかは、確認できなかった。
- **訂正印:** 二重線で消し、訂正印を押して、作成者自身の修正だと示す。削除と加入の文字数を書き添える例がある。修正液や修正テープは避ける。金額、日付、契約条件などの重要な変更は、覚書や変更契約書で行うのが一般的である。一方の当事者だけが訂正しても、原則として他の当事者に効力は生じない。
- **契印と割印:** 契印は、複数ページの一体性を示し、抜き取りと差し替えを防ぐ。割印は、同じ内容の複数部の同一性を示す。どちらも法律上の義務でなく、商慣習である。
- **大字（壱、弐、参）:** 書き足しによる改ざんを防ぐ。戸籍法施行規則 31 条が戸籍の年月日の記載に用いると定める（要約）。領収書などでの使用は慣行で、契約書での義務は見当たらなかった。
- **捨印:** 余白にあらかじめ押す印で、相手に訂正の権限を与える。金額や期間などの重要事項を、無断で書き換えられるおそれがある。信頼できない相手には、押さないのが安全とされる。

確認していないこと: 地紋、筆圧の側光による検知、薬品で変色する用紙、筆跡の一貫性の点検。出典のない解説に出てきた。
