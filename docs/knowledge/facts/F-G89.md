# F-G89. BFF は、トークンを画面に出さず、機密クライアントとして新しい認可でのトークンの取得も防ぐ。画面でコードを動かされたときの、BFF を通した要求は防げない

6.1 節は、BFF が機密クライアントとしてトークンを持ち、画面には Cookie のセッションだけを渡す形を定める。Cookie には `Secure` と `HttpOnly` を付け（MUST）、`SameSite=Strict`、パス `/`、`__Host-Http-` の接頭辞を勧める（SHOULD）。CSRF の対策を必須とし（MUST）、事前確認の要る要求に限る方法を挙げる。転送先は、明示した一覧に限る（MUST）。

6.1.4.2 節は、トークンの持ち出しと、新しい認可でのトークンの取得を防ぐとする。後者は、認可コードを手に入れても、クライアントの資格がないと替えられないためである。6.1.4.1 節は、画面でコードを動かされると、利用者のブラウザを通して BFF へ要求を送られること（5.1.4 節）は防げないとする。
