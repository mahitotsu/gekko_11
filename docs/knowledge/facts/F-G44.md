# F-G44. トークンの交換の応答に `cnf` を返し、送信者の結び付けの格下げを知らせる草案がある

送信者の結び付けをしたなら、交換の応答に `cnf` を入れる（MUST）。クライアントは、`cnf` がなければ、結び付けのないトークンとして扱う（MUST）。応答の `cnf` が示すのは、認可サーバーが格下げしなかったことだけである。個人の草案である。
