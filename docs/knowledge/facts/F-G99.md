# F-G99. Windows Hello での passkey の確認画面が出るまでは、Chrome で 1.8 秒ほど、VS Code に内蔵されたブラウザで 5 秒ほどで、アプリ側の手では変わらなかった

- **測り方:** Chrome では、要求を出してから、ウィンドウがフォーカスを失う（Windows Hello の画面が前に出る）までを、console に ms で出した。VS Code に内蔵されたブラウザは、console を開けなかったので、体感で測った。
- **Chrome の値:**

  | 操作 | 手あり | 手なし |
  |---|---|---|
  | ログイン（`allowCredentials` は 0 件） | 1760 ms、1829 ms | — |
  | 署名（`transports` は `internal`） | 1866 ms、1840 ms | 1851 ms、1828 ms |

  「手」は、hints（`client-device`）、`allowCredentials` の `transports`、ページを開いたときの `isUserVerifyingPlatformAuthenticatorAvailable()` の 3 つである。ログインの 2 回目は、手を外す設定がログインの画面の origin に入らず、手ありのまま測った。
- **VS Code に内蔵されたブラウザ:** ログインで 5 秒ほど（体感）。同じ操作の Chrome の体感は 2〜3 秒だった。
- **通信:** 確認画面を待つ間、ブラウザの network には何も出なかった。PIN を入れて OK か取消しを押した後に、フォームの送信が出た。
- **transports:** Windows Hello で作った passkey の `transports` は `internal` で、保険会社の一覧から署名の要求まで届いた（F-G100）。
- **分からないこと:** 1.8 秒の内訳（ブラウザと Windows のどちらでかかるか）は、この測り方では分からない。Edge、ほかの OS、ほかの認証器では測っていない。
