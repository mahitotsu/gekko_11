# I-B8. 営業員は登録が要り、顧客に氏名を明らかにする。顧客が登録を照会する方法は確認できず

保険業法 276 条は、特定保険募集人（生命保険募集人、損害保険代理店、少額短期保険募集人）に、内閣総理大臣の登録を求める（要約による。条文は取得できなかった）。登録の申請などは、法 284 条により、所属保険会社を代理人としてとりまとめて行える（要約のみ）。

監督指針 II-4-2-1 (3) ②は、特定保険募集人の登録を求める。法 294 条 3 項と規則 227 条の 2 に基づく、顧客に明らかにする氏名の管理を、II-4-2-2 (2) が求める。II-4-2-2 (3) ④は、意向確認書面に、保険募集人の氏名・名称を記載することと、取り扱える保険会社の範囲を説明することを求める。II-4-2-9 (4) は、保険会社のために契約の締結の代理・媒介を行う立場を誤解させる表示を禁じる。

確認できなかったこと: 顧客が募集人の登録を照会する方法と、登録が失効した後の扱い。営業員の身分証の交付・回収は、未読である。金融庁のチェックリストに記述があるという要約が出たが、PDF の本文を取り出せなかった。
