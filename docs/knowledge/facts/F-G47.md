# F-G47. Envoy の ext_authz は、外の確かめのサービスに相手の証明書を渡せ、有効にする割合を runtime の値で再起動なしに変えられる

`include_peer_certificate` を `true` にすると、相手の X.509 証明書を、確かめのサービスに渡す。`filter_enabled` は、runtime の値で、確かめる要求の割合を決める。経路ごとに無効にもできる。runtime の値は、管理の受け口（`/runtime_modify`）で変えられる（この部分は要約で確かめた）。管理の受け口は、安全な経路からだけ届くようにする必要がある。

mTLS の SAN の照合（`match_typed_subject_alt_names`）は、信頼する認証局と一緒に使い、runtime の値で切り替える項目はない。
