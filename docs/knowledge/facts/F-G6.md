# F-G6. CIBA は、取引を始める端末と、承認する端末を分けられる

CIBA は、ユーザーが使う消費デバイスと、認証と同意に使う認証デバイス（多くはスマートフォン）を分ける。消費デバイスの例として、銀行窓口の端末が挙がっている。`binding_message` を両方の端末に表示して、同じ取引だと確かめさせる（§7.1）。結果の受け取りは、poll、ping、push の 3 つのモードがある。
