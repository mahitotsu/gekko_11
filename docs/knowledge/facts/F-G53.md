# F-G53. SPIRE の agent は、同じノードで同じ SPIFFE ID の Pod に、同じ SVID（同じ鍵）を配るので、証明書への結び付けで区別できるのは、SPIFFE ID とノードの組までである

同じノードに置いた insurer-mcp と、同じ ServiceAccount の 2 つの Pod は、同じ証明書のサムプリントを持った。agent は、登録の 1 件ごとに SVID を 1 つ作り、当てはまる Pod の全てに渡す。別のノードに置いた Pod は、別の SVID を持った。

そのため、同じノードで動く同じサービスの複製が乗っ取られると、その複製は、正規の Pod に結んだトークンを使える。証明書への結び付け（D-7、D26）が止めるのは、別の SPIFFE ID の者と、別のノードの複製である。試作の確かめ（7b）では、盗んだトークンを使う複製を、別のノードに置いた。
