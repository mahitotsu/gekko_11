# I-B6. 取引時確認は、本人確認書類の原本で行い、確認の記録を作る。代理人は本人と代理人の両方を確認する

かんぽ生命の案内では、保険契約の申込み、満期保険金などの支払い、契約者の変更のとき、取引時確認を行う。個人は、マイナンバーカード、運転免許証、在留カードなどで、氏名・住居・生年月日を確認し、取引の目的と職業は申告を受ける。コピーの提示だけでは、本人確認書類と認められない。代理人が申し込むときは、本人と代理人の両方の本人確認書類が要る。確認の記録を作るため、証明書類の IC チップの情報を取得する。既に取引時確認を行った契約は、原則として再度の確認を行わない。

金融庁の監督指針 II-4-8-2 は、犯罪収益移転防止法に基づく取引時確認と、取引記録の作成・保存を求める。厳格な確認が要る取引（なりすましの疑いなど）には、追加の確認を求める。統括管理者の選任、社内規則、研修、定期的な点検と内部監査も求める。

確認できなかったこと: 確認の記録と書類の写しを、営業員が事務センターへ回す方法。証券の備考欄に確認済みを記載する運用は、検索結果の要約に出たが、案内の本文では確認できなかった。代理店が確認の記録を作成・保存する扱い。
