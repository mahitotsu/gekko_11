# F-G86. Keycloak 26.8.1 で更新した A は、取決めの範囲、may_act、確認済みの属性、cnf を保ち、発行の記録が残る。使い回すと、ログインごと更新できなくなる

`use.refresh.tokens` を真にし、`revokeRefreshToken` を真、`refreshTokenMaxReuse` を 0 にして、次を確かめた。
- 更新した A は、`sub`、`aud`、`cnf`、`may_act`、`verified_claims`、`authorization_details` を保つ。`jti` は新しく、有効期間は 5 分である。
- `IssuanceMapper` は、更新のたびに発行の記録を書く。
- proof のない更新は `invalid_request`、別の鍵の更新は `invalid_grant` で断られる。
- 古い更新のトークンを出すと `Stale token` で断られ、以後は最新の更新のトークンも使えない。
- P を `prompt=none` で受け取った後も、A の更新のトークンは使える。

ほかの版では確かめていない。
