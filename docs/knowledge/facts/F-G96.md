# F-G96. Keycloak 26.8.1 の ID トークンの amr は、通った認証の段ごとに設定した値から作られる。設定がなければ空で、passkey でのログインはパスワードと同じ段の中で行うので、標準の流れでは両者を区別できない

- AMR のマッパー（`oidc-amr-mapper`）を足しただけでは、3 通りのどのログインでも `amr` は空だった。
- `AmrUtils` は、認証の間に通った段（execution）ごとに、その段の設定の `default.reference.value` を集める。
- passkey を有効にした 26.8.1 の標準のログインでは、passkey でのログインも、ユーザー名とパスワードのフォームの段の中で行う。そのため、段に値を設定しても、パスワードと passkey は同じ値になる。
- 区別するには、passkey を別の段に分けたログインの流れを作る必要がある。

ほかの版では確かめていない。
