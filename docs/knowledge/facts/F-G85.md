# F-G85. Keycloak は、公開クライアントでは、アクセストークンと更新トークンの両方を DPoP の鍵に結ぶ

公開クライアントでは、両方のトークンを鍵に結び、更新の要求にも同じ秘密鍵の proof を求める。機密クライアントでは、アクセストークンだけを結ぶ。
