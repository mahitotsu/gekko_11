# F-G20. RFC 8785 は、署名やハッシュのために、JSON の書き方を一つに揃える

JCS は、JSON の一意な正規表現を定める。空白を出力せず、オブジェクトのキーを再帰的に並べ替える（UTF-16 コードユニットで比較）。配列の順は変えない。数値は ECMAScript の規則に従い、最後に UTF-8 にする。元の JSON を送受信しつつ、暗号処理は正規化した結果に対して行える（§1、§3.2）。
