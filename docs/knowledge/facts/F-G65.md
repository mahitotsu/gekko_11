# F-G65. Envoy 1.31 の CORS のフィルターは、許した origin からの事前確認の要求に自分で答え、後ろの ext_authz（token-guard）へ渡さない

入口の `agent.<名前空間>.localhost` に、`Origin: http://app.<名前空間>.localhost:<ポート>` と `Access-Control-Request-Headers: authorization,dpop,content-type` の OPTIONS を送ると、入口が 200 と `access-control-allow-*` を返した。トークンのない要求は、営業 AI エージェントの token-guard に届けば 401 になる。

このリポジトリは、CORS を入口だけで扱い、サービスと token-guard には CORS の設定を置かない（D-25）。
