# F-G36. Okta の代理のトークンの交換は RFC 8693 に従い、`act` を `act.act` で入れ子にし、5 段までとする

Okta の代理のトークンの交換は、`grant_type` に `urn:ietf:params:oauth:grant-type:token-exchange` を使う。`act` は、交換を頼んだサービスのアプリを示す。出されたトークンにすでに `act` があれば、`act.act` に入れ子にする。委任の連鎖は、5 段までである。

DPoP と mTLS の結び付けと、交換との関係は、確かめていない（Okta の DPoP の手引きは、本文を読めなかった）。
