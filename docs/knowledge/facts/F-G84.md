# F-G84. 公開クライアントの更新トークンは、送信者に拘束するか、ローテーションする。使い回しを検知したら、有効な更新トークンを取り消す

2.2.2 節は、公開クライアントの更新トークンについて、送信者の拘束かローテーションを MUST とする。4.14.2 節は、次のことを定める。
- 更新トークンを出すかは、リスクの評価で決める（MUST）。
- 更新トークンは、同意された範囲とリソースに結ぶ（MUST）。
- ローテーションでは、無効にした更新トークンが示されると、どちらが正規の者か分からないので、有効な更新トークンを取り消す。正規の者も、認可を取り直すことになる。
- ログアウトなどの出来事で、更新トークンを取り消してよい（MAY）。
- 使われない期間が続いたら、更新トークンを切らす（SHOULD）。
