# F-G28. W3C の Verifiable Credentials Data Model 2.0 は、発行者が主張に署名した資格情報を、保有者が検証者に示す形を定める勧告である

検証可能な資格情報は、改ざんが分かり、作成者を暗号で検証できる資格情報である（§2）。役は 3 つある（§1.2、§2）。発行者（issuer）は、主張を資格情報にして保有者に渡す。保有者（holder）は、資格情報を持ち、提示を作る。検証者（verifier）は、資格情報を受け取って処理する。提示は、保有者が作り、複数の資格情報のデータをまとめて、検証者に示す（§3.3）。適合する文書は、少なくとも 1 つの守りの仕組みで守られていなければならない（§1.3）。仕組みには、Data Integrity による埋め込みの証明と、JOSE や COSE による包む証明がある。2025 年 5 月 15 日の W3C 勧告である。
