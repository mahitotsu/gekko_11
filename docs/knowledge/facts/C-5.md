# C-5. 代理の効果は、代理権の存在、顕名、権限の範囲内で本人に帰属する。無権代理は、追認がなければ本人に効力が生じない

民法 99 条は、代理人が権限の範囲内で、本人のためにすることを示してした意思表示は、本人に対して直接に効力を生ずると定める。要件は、代理権があること、本人のためにすることを示すこと（顕名）、代理権の範囲内であることと整理される。113 条は、代理権のない者の契約は、本人が追認しない限り、本人に効力を生じないと定める。
