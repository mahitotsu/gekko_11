# I-A2. 比較可能な商品の概要を示し、推奨の理由を説明する。手数料水準で誘導しない

二以上の所属保険会社等を持つ保険募集人は、顧客の意向に沿った比較可能な商品の概要を示し、求めに応じて内容を説明する。特定の商品を提示・推奨するときは、その理由を分かりやすく説明し、商品特性や保険料水準などの客観的な基準を示す。手数料水準などを理由に商品を誘導しない。保険会社等に過度な便宜供与を求めたり受けたりしないよう、社内規則と監視体制を整える。
