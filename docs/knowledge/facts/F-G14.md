# F-G14. RFC 8725 は、署名、アルゴリズム、aud、typ を検証し、別の種類の JWT との取り違えを防ぐよう勧める

JWT のベストプラクティスである。
- **アルゴリズム:** 呼び出し側が、許可するアルゴリズムの集合を指定できるようにし、それ以外を使わない（§3.1）。`none` は、他の手段で暗号的に保護されている場合に限る（§3.2）。各鍵は、1 つのアルゴリズムでのみ使う（§3.1）。
- **署名:** 全ての暗号操作を検証し、1 つでも失敗したら拒否する（§3.3）。
- **iss と sub:** `iss` がある場合、鍵が発行者に属することを確かめる。`sub` が、アプリケーションで有効な主体に対応するかを確かめる（§3.8）。
- **aud:** 同じ発行者が複数の受信者向けに発行するなら、`aud` を含める。受信側は検証し、自分に該当しなければ拒否する（§3.9）。
- **typ:** `typ` で JWT の種類を明示し、検証規則で確かめる（§3.11）。
- **取り違え:** 同じ発行者の異なる種類の JWT は、検証規則が互いに排他的でなければならない。対策は、`typ`、必須クレーム、鍵の分離、`aud` や `iss` の使い分けである（§2.8、§3.12）。
