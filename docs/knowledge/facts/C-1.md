# C-1. 承認者は申請内容を修正できず、差し戻すか取り下げさせる（法人向け外為）

りそな銀行の法人向け外為サービスのマニュアルでは、承認者は承認依頼を受けた取引を自分で修正できず、依頼者への差し戻しか、依頼者による取り下げが要る。DX 後のサービスだが、入力者と承認者を分ける統制の現在の形である。
