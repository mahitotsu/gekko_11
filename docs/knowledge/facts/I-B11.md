# I-B11. 無選択型の個人年金保険は、健康状態の告知も医師の診査も要らない

生命保険を契約するときは、通常、健康状態などの告知か、医師による診査が要る。「無選択型」の保険では、告知も医師による診査も要らない。無選択型の保険には、終身保険や個人年金保険がある。取り扱う生命保険会社がある、という書き方で、全ての会社が扱うわけではない。

告知のある個人年金保険では、保険料の払込期間中に所定の高度障害状態などに当たると、以後の保険料の払込みが免除される。無選択型の個人年金保険には、この保険料の免除の扱いがない。
