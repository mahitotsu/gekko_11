# I-D3. 事務センターが、回付された申込みの営業員を確認する方法は、確認できなかった

申込書の募集人欄に、代理店コードや募集人コードを記載するかは、確認できなかった。事務センターが登録の有効性を確認するか、権限外の申込みをどう扱うかも、確認できなかった。登録の申請は所属保険会社が代理して行える（I-B8、要約のみ）。そのため、会社は自社の営業員の登録を把握している（推定）。
