# F-G10. RFC 7009 は、トークンの失効を認可サーバーに依頼する

クライアントが、不要になったトークンを、失効エンドポイントに依頼して失効させる。失効は即座に行われ、失効後のトークンは再利用できない。ただし、サーバー間の伝播に遅れがありうる（§2.1）。アクセストークンの失効に対応しない認可サーバーでは、リフレッシュトークンを失効させても、アクセストークンはすぐには無効にならない（§5）。
