# I-F3. 不祥事件は、届出と通知の対象で、類似の疑いがあれば伏在調査を行う

特定大規模乗合保険募集人で起きた不祥事件は、届出を行った保険会社以外の所属保険会社等にも、概要を通知する。類似の不祥事件の疑いがあれば、関係者の氏名などを通知し、伏在調査を行う。重大な問題があれば行政処分の対象になる。
