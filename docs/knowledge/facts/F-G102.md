# F-G102. CSP の style-src は、'unsafe-inline' がなければ、要素の style 属性を止める

- style 属性の確かめ（6.1.15.1）は、要素が一覧に合わなければ「Blocked」を返す。
- `style-src-attr` がなければ、`style-src`、`default-src` の順に使う（6.8.3）。
- 一覧がインラインを全て許すのは、`'unsafe-inline'` を含み、nonce とハッシュを含まないときだけである（6.7.3.2）。
- 「Nonces only apply to inline script and inline style, not to attributes of either element」（6.7.3.3 の注）。<!-- check-docs: 残す 原文の引用を含み、区切ると照らせなくなる -->style 属性をハッシュで許すには、`'unsafe-hashes'` が要る。

読んだのは、6 章の該当の節と 1.3 節である。仕様は Working Draft である。
