# C-4. 真正性は、情報セキュリティの用語で、主体や情報が主張どおりであること。取引の用語ではなく、定義は文献でばらつく

ISO/IEC 27000 と、対応する JIS Q 27000 で、真正性（authenticity）は、主体や情報が、主張するとおりのものであるという特性とされる。機密性、完全性、可用性に並べて扱われる。取引についての定義ではない。JNSA の資料は、定義が文献ごとにばらつくと指摘している。電子帳簿保存法の国税庁の資料は、改ざん防止の要件を「真実性の確保」と呼ぶ。会計監査では、取引について、実際に起きて企業に帰属すること（発生）、正しい金額で記録されること（正確性）を、アサーションとして区別する（ISA 315）。
