# F-G80. Keycloak 26.8.1 は、DPoP の htu を要求の Host で照らし、ブラウザの Origin を webOrigins で照らす。確かめられない id_token_hint には、エラーの画面を返す

- `--hostname` を固定しても、DPoP の `htu` は、要求そのものの URL（Host の名前）と照らす。内部の名前で呼ぶと「DPoP HTTP URL mismatch」で断る。公開名の Host で呼べば通る。
- トークンの要求の `Origin` が `webOrigins` にないと、「Invalid origin」で断る。入口のプロキシで CORS を処理しても、この確かめは残る。
- `/logout` に確かめられない `id_token_hint` を付けると、400 のエラーの画面になり、戻り先へ戻らない。`id_token_hint` を付けなければ、確認の画面（`#kc-logout`）を出し、押すと戻り先へ戻る。
