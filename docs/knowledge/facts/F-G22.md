# F-G22. OpenID Connect Core 1.0 の ID トークンは、認可サーバーによる利用者の認証についての署名つき JWT で、宛先はクライアントである

ID トークンは、認可サーバーによる利用者（End-User）の認証についての Claim を含むセキュリティトークンで、JWT で表す（§1.2、§2）。JWS で署名しなければならない（MUST、§2）。`iss`、`sub`、`aud`、`exp`、`iat` が必須で、`aud` は依拠する側（Relying Party）の `client_id` を含まなければならない（§2）。

認可サーバーは、ID トークンと、通常はアクセストークンを返す。依拠する側は、アクセストークンを UserInfo エンドポイントに示して、利用者の情報を受け取る（§1.3）。

読んだのは §1〜§3.1 である。ID トークンの検証の手順（§3.1.3.7）は、本文を確かめていない。
