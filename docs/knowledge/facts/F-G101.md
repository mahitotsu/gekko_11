# F-G101. Keycloak 26.8.1 のテーマの静的なファイルは 30 日キャッシュされ、配置し直しても古いスクリプトが残る

- **見たこと:** 写したスクリプトを置いて配置し直した後も、URL は `/resources/zs2k2/login/insurer/js/webauthnAuthenticate.js` のままで、`cache-control: max-age=2592000` だった。Chrome は前のスクリプトを使い、足した表示も記録も出なかった。画面のテストは、毎回新しいブラウザで動くので、通った。
- **直したこと:** 起動の引数に `--spi-theme--static-max-age=-1` を足すと、`cache-control: no-cache` になった。このときは URL の版も替わった（`7dmwf`）。
