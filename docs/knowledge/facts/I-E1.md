# I-E1. クーリング・オフは、申込日か書面の受領日の遅いほうから 8 日以内

解説では、クーリング・オフは、保険会社宛てに書面または電磁的記録で、8 日以内に申し出る（保険業法 309 条）。起算は、申込日と、クーリング・オフに関する書面の受領日の遅いほうである。申込みを受けた代理店には出せない。保険期間が 1 年以内の契約、法人契約などは対象外。会社により期間が延びる場合がある。取り消すと、保険料は全額返金される。
