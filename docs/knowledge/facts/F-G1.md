# F-G1. RFC 8693 は、委任を `act` クレームで表し、入れ子で連鎖を表す

token exchange は、クライアントが認可サーバーを使って、別のトークンを要求する仕組みである。委任（本人の代わりに、自分の ID を保って動く）では、トークンに主体と行為者の両方が入る。`act` クレームが現在の行為者を表し、過去の行為者は入れ子で表す。アクセス制御の判断では、最も外側の行為者だけを考慮し、入れ子の過去の行為者は情報として扱う（§4.1）。
