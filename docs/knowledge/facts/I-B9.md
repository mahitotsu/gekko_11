# I-B9. 高齢者の募集では、親族の同席、複数の募集人、別の担当者による電話確認などを挙げる

監督指針 II-4-4-2-1 (4) は、高齢者への保険募集の措置の例を挙げる。親族等の同席を求める。複数の保険募集人で募集する。複数回の募集機会を設け、検討の時間を確保する。募集担当者以外が、申込みの受付後に、電話等で意向を確認する。募集内容を記録・保存し、契約後にフォローアップする。「意思能力」と「勧誘の時間帯」の記載は、見つからなかった。
