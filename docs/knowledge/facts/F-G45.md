# F-G45. SPIFFE によるクライアント認証の草案は、X.509-SVID を RFC 8705 の mTLS で、JWT-SVID を専用のアサーションで使う

OAuth の WG の草案である。X.509-SVID による認証は、RFC 8705 の mTLS のクライアント認証を使い、要求の `client_id` に SPIFFE ID を入れる（MUST）。JWT-SVID は、`client_assertion_type` に `urn:ietf:params:oauth:client-assertion-type:jwt-spiffe` を使う。トークンの交換と、出すトークンの結び付けには、読んだ範囲で触れていない。
