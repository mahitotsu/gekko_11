# I-B2. 意向を把握し、意向確認書面を作成・交付・保存する

監督指針 II-4-2-2 (3) は、顧客の意向を把握して、それに沿った保険契約の提案を行うことを求める。④イ (ア) で、顧客の意向に関して情報を収集し、保険商品が意向に合致することを確認する書面（意向確認書面）の作成・交付・保存を挙げる。2006 年の検討資料には、意向確認書面に、顧客のニーズ、推奨商品が合うと考えた主な理由、満たされないニーズを記載する考え方があった。顧客が事実に反する記載を修正できるようにする考え方もあった（二次の検討資料。現行の記載は未確認）。
