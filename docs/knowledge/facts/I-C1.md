# I-C1. 契約概要と注意喚起情報を交付し、口頭で説明して、了知を確認する

監督指針 II-4-2-2 (2) は、契約の内容を理解するための「契約概要」と、注意を促す「注意喚起情報」の交付を求める。契約概要は商品の仕組み、保障内容、保険期間、保険料など。注意喚起情報は、クーリング・オフ、告知義務、責任開始期、免責事由、解約返戻金などである。書面の交付に加えて、重要事項を口頭で説明し、顧客が内容を了知したことを確認する体制を求める。
