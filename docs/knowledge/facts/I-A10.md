# I-A10. 年金額から保険料を出す公式な例、計算の担い手、設計書の発行者と有効期限は、確認できなかった

個人年金の解説、導入事例、募集の規則を調べたが、次の点は見つからなかった。年金額から保険料を計算する、保険会社の公式な例。保険料の計算と商品の規定の確かめを、端末と保険会社のシステムのどちらが担うか。設計書を誰が発行し、いつまで有効か。代理店向けの設計書システムを保険会社が持つことは、求人情報の要約（<https://www.kotora.jp/job/detail.php?jid=128727>）で見ただけである。
