# F-G100. Keycloak 26.8.1 は passkey の transports を持つが、標準のログインのスクリプトは添えない

- **持つもの:** `WebAuthnCredentialData` に `transports` の欄がある。認可サーバーが管理の API で読む credentialData にも入り、署名の要求まで運べた（Windows Hello では `internal`。F-G99）。
- **ログインのスクリプト:** `authenticateByWebAuthn` は、`isUserIdentified` が偽なら `allowCredentials` を空にする。真のときは、画面の隠しフォーム（`authn_select`）から識別子だけを読む。transports は、画面の表示（アイコンと名前）にだけ使う。
- **この realm:** ログインの画面の「パスキーでログイン」は、利用者を特定する前に押すので、`allowCredentials` は空である（F-G99 のログイン）。
