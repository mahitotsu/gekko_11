# F-G43. OAuth の Actor Profile（個人の草案）は、新しい提示者の `actor_token` と所持の証明で、出すトークンを結び直す手順を定める

一番外の `cnf` は、今の提示者の鍵か証明書を示す。受け取る側は、一番外の `cnf` で所持を確かめる（MUST）。提示者の結び直しには、新しい提示者を一番外の `sub` で示す、確かめた `actor_token` が要る。出すトークンを結ぶなら、発行者は新しい提示者の所持の証明を確かめる（MUST）。結び付けた subject のトークンでも、結び直しのときに、前の提示者の証明は求めない。前の段の鍵の来歴は、範囲外とする。

個人の草案で、IETF の承認を得たものではない（標準化を目指す）。
