# I-A5. 基本型の募集は、意向の把握、個別プランの提案、関係の説明、最終の意向の確定、当初との比較、合致の確認の順に進む

解説は、意向把握型（基本型）の手順を次の順で示す。アンケート等で意向を事前に把握する。意向に沿った個別プランを作成・提案する。把握した意向と個別プランの関係性を説明する。最終的な意向を確定する。最終的な意向と当初把握した主な意向の比較を記載し、相違点があれば経緯等を説明する。最終的な意向と契約の内容が合致しているかを確かめる。契約を締結する。監督指針の現行の本文は読んでいない。
