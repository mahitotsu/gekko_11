# F-G59. Envoy 1.31.5 では、受け口に検証の設定（ROOTCA）を入れると、証明書を求めない設定でも、証明書のない相手を拒んだ

`DownstreamTlsContext` に `validation_context_sds_secret_config`（ROOTCA）を入れ、`require_client_certificate` を偽にした。証明書を示さない相手（顧客の役）は、TLS の警告 `certificate required` で拒まれた。検証の設定を外すと、つながった。原因は、確かめていない。

このリポジトリは、顧客の受け口（営業 AI エージェント、顧客のアプリ）には検証の設定を入れない。顧客のアプリは、顧客向けの受け口と、保険会社のシステムからの直送を mTLS で受ける受け口を分ける。
