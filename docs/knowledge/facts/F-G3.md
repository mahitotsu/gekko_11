# F-G3. RFC 9470 は、リソースサーバーが認証の強さと新しさを要求できる

API が要求ごとに異なる認証の強さや新しさを求める場合に、リソースサーバーが `insufficient_user_authentication` エラーと `acr_values`、`max_age` で要件を伝える。クライアントは、それを認可サーバーへの再認証要求に付ける。トークンの `acr` と `auth_time` で、リソースサーバーが確認する。
