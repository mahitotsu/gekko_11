# F-G12. RFC 7591 は、クライアントを認可サーバーに登録する。署名つきの主張（software statement）も使える

動的クライアント登録は、クライアントを認可サーバーに登録し、識別子（`client_id`）とメタデータを結び付ける。メタデータの例は、名称（`client_name`）、連絡先（`contacts`）、要求できる権限（`scope`）、公開鍵（`jwks`）、ソフトウェアの識別子（`software_id`）である（§2）。

software statement は、クライアントのメタデータを主張する、署名または MAC つきの JWT である。発行者を示す `iss` が必須で、発行者は開発者自身でも、第三者でもよい（§1.2、§2.3）。認可サーバーが発行者をどこまで信頼するかの基準は、仕様の対象外である。同じメタデータが本体と statement の両方にあれば、信頼される statement の値が優先される（§2、§5）。
