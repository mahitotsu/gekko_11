# F-G66. AG-UI 1.0 は、HTTP の POST で RunAgentInput を送り、SSE の data に 1 つずつイベントを返す。画面側の道具は RunAgentInput.tools で渡し、その結果は tool message として会話に戻す

- **運び方（HTTP と SSE）:**
  - 要求: 利用者の側は、エージェントの受け口に `POST` で、RunAgentInput を 1 つの JSON（`Content-Type: application/json`）として送る。`Accept: text/event-stream` を付ける。
  - 応答: 回が始まれば、`200` と `Content-Type: text/event-stream` で答える。SSE の各イベントの `data` は、ちょうど 1 つのイベントの JSON である。
  - 回が始まる前の拒否は、イベントの列のない HTTP の誤りの状態で返す。始まった後の失敗は、列の中の `RUN_ERROR` で返す。
- **RunAgentInput:** `threadId`、`runId`、`messages` が必須である。`tools`、`context`、`state`、`forwardedProps`、`resume` などは任意である。
- **回の境目:** `RunStarted` と、`RunFinished` か `RunError` が必須で、回の境目を作る。
- **画面側の道具:** 利用者の側の道具は、`RunAgentInput.tools` で渡す。エージェントは `TOOL_CALL_START`、`TOOL_CALL_ARGS`、`TOOL_CALL_END` を出す。結果は、`role: "tool"` と `toolCallId` を持つ tool message として、会話の履歴に戻す。
- **interrupt:** 回を `RunFinished` の `outcome: interrupt` で終え、`resume` で再開する方式もある。ただし、events のページは、これを DRAFT と記す。

このリポジトリは、画面側の道具の結果を、次の回の tool message で返す（D-29）。interrupt は使わない。
