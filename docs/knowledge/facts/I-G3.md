# I-G3. 保険料は領収証を発行し、代理店が領収した保険料は区分して会社に精算する

監督指針 II-4-2-1 (4) ②ア (イ) は、保険料の支払いを受けたとき、保険料領収証を発行することを求める。代理店が領収した保険料は、自己の財産と明確に区分し、遅滞なく適時に保険会社へ精算するよう求める。かんぽ生命は、社員が現金を預かるときは領収証を渡し、払込票は顧客自身が金融機関で払い込み、社員が代わりに払い込むことは絶対にないと案内する。ある損害保険会社は、現金・小切手の支払いには代理店が会社所定の領収証を発行し、会社へ直接振り込んだ場合は領収証を省略する。会社所定以外の領収証を受け取ったときは、問い合わせるよう案内している。
