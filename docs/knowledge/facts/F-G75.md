# F-G75. k3d 5.9 の image import は、手元にない CPU の分を参照するイメージが混ざると、その回の全てのイメージの取り込みに失敗する。それでも成功と表示する

`docker pull` した grafana/loki:3.7.8 は、複数の CPU 向けの目次を持ち、手元には amd64 の分だけがある。ほかのイメージと一緒に `k3d image import` すると、ノードの `ctr` が「content digest ... not found」で止まり、その回のどのイメージも入らなかった。k3d は、そのあとに「Successfully imported」と表示し、終了コードも 0 だった。

`docker save --platform linux/amd64` で、手元の CPU の分だけを書き出したファイルは、ほかの CPU の分を参照せず、取り込めた。
