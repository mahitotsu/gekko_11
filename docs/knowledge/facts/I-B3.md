# I-B3. 申込書には契約者と被保険者が署名し、告知は書面で本人が行う

生命保険文化センターの手引では、申込書には契約者と被保険者がそれぞれ署名する。生命保険会社が指定した医師以外（営業職員や代理店の担当者など）に、健康状態などを口頭で伝えても、告知したことにはならない。告知は書面で行う。
