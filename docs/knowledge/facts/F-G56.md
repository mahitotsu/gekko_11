# F-G56. SPIFFE は、同じ仕事をする複製をまとめて 1 つの workload とし、workload どうしが互いの証明書を盗めないことを前提に置く

SPIFFE は、workload を、特定の設定で 1 つの目的のために置いたソフトウェアと定義する。workload は、同じ仕事をする複数の動いている実体からなりうる。多くのノードにまたがることもある。SPIFFE ID は workload を表し、SVID は 1 つの SPIFFE ID を持つ。

SPIFFE は、悪意のある workload が、発行済みの他者の証明書を盗めない程度に、workload どうしが隔離されていると仮定する。隔離の強さと実現の方法は、SPIFFE の範囲外とする。

SPIRE が、同じノードで同じ SPIFFE ID の Pod に同じ SVID を配ること（F-G53）は、この定義に沿う。
