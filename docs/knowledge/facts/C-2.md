# C-2. 窓口で、高額の振込や払戻しに声をかける取組がある

金融庁は、金融機関の店頭で、投資詐欺などを水際で防ぐために、預貯金の引出しや振込の際に職員が声をかけることがあると説明している。警察の資料には、職員 2 名が用途の説明が不明瞭な高額取引を不審に思い、被害を防いだ事例がある。
