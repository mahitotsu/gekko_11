# F-G105. Bootstrap 5.3 の色のモードは、data-bs-theme で切り替わり、OS の設定には自動で従わない

`<html>` に `data-bs-theme="dark"` を付けると、暗い色になる。既定の作りは「does not automatically toggle your project’s color mode」である。公式の例のスクリプトは、`window.matchMedia('(prefers-color-scheme: dark)')` で OS の設定を読み、属性を付ける。
