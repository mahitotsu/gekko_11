# F-G46. Envoy の jwt_authn は署名、iss、aud、exp を確かめるが、DPoP、cnf の結び付け、typ は確かめず、検証を再起動なしに切り替えられない

jwt_authn は、JWT の署名、`aud`、`iss` を確かめ、`exp` を確かめられる（`require_expiration`、時計のずれは既定で 60 秒）。要求ごとに、ヘッダーや経路で、求める確かめを選べる。確かめを緩める型（`allow_missing`、`allow_missing_or_failed`）もある。確かめた中身は、動的なメタデータに書ける（`payload_in_metadata`）。

文書には、DPoP、`cnf`、証明書に結んだトークン、`typ` の確かめが出てこない。検証を runtime の値で切り替える項目もない。
