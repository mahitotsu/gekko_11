# F-G88. oidc-client-ts 3.3.0 は、DPoP の取り出せない鍵と更新を扱うが、ID トークンの署名は確かめない。nonce は渡したときだけ確かめ、利用者を消すと鍵も消す

パッケージの中身と、画面のテストで次を確かめた。
- `dpop` の設定で、WebCrypto の取り出せない鍵を作り、IndexedDB に置く。トークンの要求と更新に proof を付ける。
- ID トークンの署名を確かめるコードはない。`nonce` は、ログインのときに渡した場合だけ照らす。
- 利用者を消すと（`removeUser`）、DPoP の鍵も消す。
- A と P のように宛先の違うトークンは、保存先を分けた 2 つの `UserManager` で持てる。鍵は `client_id` で共有する。

ほかの版では確かめていない。
