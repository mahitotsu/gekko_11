# F-G51. Spring Authorization Server は、`may_act` の `iss` を、保存した `actor_token` の `iss`（URL の型）と型ごと比べるので、文字列の `iss` は一致しない

交換の部品は、`may_act` の `iss` と `sub` を、`actor_token` の主張と `Objects.equals` で比べる。保存したトークンの主張では、`iss` が `java.net.URL` の型になる。`may_act` の `iss` を文字列で書くと、値が同じでも一致せず、`invalid_grant` で拒まれる（エラーの説明は付かない）。

このリポジトリは、`may_act` の `iss` を URL の型で書く。JWT の中では、文字列として出る。外から来たトークンの `may_act`（文字列）を照らすと、この照合は一致しない。
