# F-G91. WebAuthn では、passkey を使える origin を RP ID が決める。RP ID は、呼び出し元の origin の effective domain か、その登録可能な親ドメインでなければならない。名前の違うサイトどうしで共有する Related Origin Requests は、HTTPS の /.well-known/webauthn を取りに行く

- 4 章の RP ID の定義: 既定の RP ID は、呼び出し元の origin の effective domain である。呼び出し元は、それを、その登録可能な親ドメイン（registrable domain suffix）に替えてよい。RP ID はスキームとポートを含まない。
- 同じ定義: passkey は、登録したときと同じ RP ID の認証にだけ使える。
- 5.11.1 節: RP ID が呼び出し元の親ドメインでないときは、`https://<RP ID>/.well-known/webauthn` を、https のスキームで取りに行き、許された origin の一覧と照らす。

親ドメインが同じ 2 つの名前（例: `login.<名前空間>.localhost` と `app.<名前空間>.localhost`）は、親ドメインを RP ID にすれば、同じ passkey を使える。`localhost` の下の名前が、登録可能な親ドメインとして扱われるかは、この節では決まらない。実機では [F-G92](F-G92.md) で確かめた。
