# C-7. EARS は、要件を型で書く。望まない事態の型は「もし〜なら、システムは〜する」で、望まない状況への応答を書く

EARS（Easy Approach to Requirements Syntax）は、要件の文の型である。基本の形は、「While 前提、when きっかけ、the システム shall 応答」である。前提は 0 個以上、きっかけは 0 か 1 個、システムは 1 つ、応答は 1 つ以上とする。

型は 6 つある。常に有効な要件（キーワードなし）、状態の間（While）、出来事のとき（When）、任意の機能（Where）、望まない事態（If … then）、複合である。複合は、それらを組み合わせた型である。望まない事態の要件は、望まない状況に対して求めるシステムの応答を書くために使う。
