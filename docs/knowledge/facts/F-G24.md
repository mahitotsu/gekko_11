# F-G24. FAPI 2.0 Security Profile（最終版）は、PAR、S256 の PKCE、送信者に結んだアクセストークンを求め、公開クライアントを対象にしない

FAPI 2.0 Security Profile は、OpenID Foundation の最終版（2025 年 2 月 22 日）である。攻撃者モデルの安全の目標を満たすことと、OAuth のセキュリティの BCP に従うことを目指し、形式的な分析で攻撃者モデルを満たすと示した（§1、§5.1.1）。公開クライアントを同じ程度に守る仕組みが知られていないので、対象は秘密を持つクライアントに限る（§5.1.1）。

認可サーバーは、PAR（RFC 9126）を求め、PAR のない認可要求を拒む。PKCE は S256 で求める。アクセストークンは、送信者に結んだもの（mTLS の RFC 8705 か DPoP の RFC 9449）だけを出す。認可コードの有効期間は最大 60 秒とする（§5.3.2）。クライアントは、認可応答の `iss` を RFC 9207 で確かめる（§5.3.3.2）。JAR（RFC 9101）は、FAPI 2.0 の求めに入っていない（§5.3.1、§5.5）。

読んだのは本文の前半で、アクセストークンの有効期間の推奨（§6.1）と攻撃者モデルの詳細は、本文を確かめていない。
