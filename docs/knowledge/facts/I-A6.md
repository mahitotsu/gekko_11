# I-A6. 営業担当者が、顧客の要望を聞きながら、その場で複数のプランを設計して画面に示す例がある

太陽生命の記事は、顧客の要望を聞きながら、その場で複数のプランを設計して画面に表示できると書く。三井生命の記事は、顧客と一緒に画面を確かめながら保険設計を作成・提案すると書く。どちらも導入の発表で、計算の担い手と操作の手順は書かれていない（I-A10）。
