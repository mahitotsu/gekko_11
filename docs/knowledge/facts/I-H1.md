# I-H1. 所属保険会社等は、募集人が契約者に加えた損害を賠償する責任を負う

金融庁の資料では、所属保険会社等は、保険募集人が保険募集について保険契約者に加えた損害を賠償する責任を負う（保険業法 283 条）。保険募集人に資力要件は課されていない。
