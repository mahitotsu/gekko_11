# F-G81. Keycloak 26.8.1 は、preview の federated-jwt で、SPIRE の JWT-SVID を認可コードの流れのクライアント認証に使える。client-x509 は SPIFFE の URI SAN を見ない

機能の `spiffe` と `client-auth-federated` を有効にし、identity provider の `spiffe` に、信頼ドメインと SPIRE の bundle の受け口を設定する。クライアントは `federated-jwt` にし、`jwt.credential.issuer` と `jwt.credential.sub` で SPIFFE ID を固定する。要求には、`client_assertion_type` に `...:jwt-spiffe` を付ける。

SPIRE の bundle の受け口は、`https_web` の profile で、自己署名の証明書で開き、Keycloak は `KC_TRUSTSTORE_PATHS` で信頼する。JWT-SVID の `aud` は、realm の issuer にした。

client-x509 についての記述は、26.7.0 の確かめで、26.8.1 では確かめ直していない。
