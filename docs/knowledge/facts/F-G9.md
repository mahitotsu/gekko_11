# F-G9. RFC 7662 は、リソースサーバーがトークンの有効性を認可サーバーに問い合わせる

token introspection は、リソースサーバーが受け取ったトークンの有効性とメタ情報を、認可サーバーに問い合わせる方式である。応答の `active` が現在の有効性を示す。`scope`、`client_id`、`sub`、`aud`、`exp` なども返せる。失効、期限切れ、不明なトークンでは、`active` を false にして返さなければならない（MUST）。応答をキャッシュする間は、失効したトークンも通りうる（§4）。
