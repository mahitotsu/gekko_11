# C-8. Volere は、要件を集めるときに解を避け、解の案を要件と分ける。要件には、テストできる測り（合格の基準）を添える

要件を集めるときは、本当の要件を見つけることに集中し、解を考え出すことを避ける。解の案は、本当の要件と分けるために、別の節（Ideas for Solutions）に置く。問題の解き方を強制する制約は、解の制約（Solution Constraints）として、求める技術や解を明示する。要件の意味を曖昧なく定めるには、テストできる測り（fit criterion、合格の基準）を加える。

読んだのは、テンプレートの公開の抜粋である。要件の殻（requirements shell）の項目名は、抜粋では画像で、本文を確かめていない。
