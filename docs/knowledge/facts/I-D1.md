# I-D1. 申込みの後に、保険会社が加入を査定し、承諾する

申込みの後に、保険会社が引受基準に従って査定し、承諾すべきときに承諾する。査定には、告知書から健康面を見る医務査定と、職業や加入状況を見る環境査定がある。第 1 回の保険料は、承諾されなければ返金される。
