# I-G1. 意向把握の帳票と意向確認書面を保存する。面談の記録の保存は、銀行等の募集で明記

意向把握に用いた帳票と意向確認書面は保存する（II-4-2-2 (3) ④）。顧客との面談内容等を記録し、説明に係る記録を保険期間の終了まで保存することは、銀行等の保険募集の節（II-4-2-6-3 (5)）に明記されている。一般の保険募集について、面談内容の記録を義務付ける明確な記載は、読んだ範囲で見つからなかった。
