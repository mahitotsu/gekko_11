# I-X2. 個人情報保護法が会話の記録に求めること、保険の募集の記録の保存期間の求めは、調べていない

次の項目は、調べていない。
- 個人情報保護法が、会話の記録（顧客の文を含む）の取得、利用目的、保存、第三者への提供（モデルの提供元を含む）に求めること。
- 保険業法と監督指針が、募集の記録（意向の把握、説明の記録）の保存期間に求めること。

会話の記録の保存期間（7 日。D-32）は、法令から決めたものではない。
