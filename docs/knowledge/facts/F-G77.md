# F-G77. Spring Authorization Server 1.5.8 の標準の交換の部品は、保存先にないトークンを subject_token として受け付けない

標準の部品は、`subject_token` を `OAuth2AuthorizationService.findByToken` で探し、なければ `invalid_grant` で拒む。見つかっても、有効であること、保存された認可に `Principal` の属性があることを求める。`may_act` は保存された主張から読み、`actor_token` の `iss` と `sub` を `Objects.equals` で比べる（型については F-G51）。そのため、ほかの発行者のトークンを替えるには、確かめて保存先に入れる処理を、組み込む側が書く。
