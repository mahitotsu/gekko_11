# F-G38. Microsoft Entra ID の代理の流れは RFC 8693 の交換ではなく、DPoP は公開クライアント向け、mTLS の結び付けはサービス間向けである

Entra ID の代理の流れ（On-Behalf-Of）は、`grant_type` に `urn:ietf:params:oauth:grant-type:jwt-bearer` を、`requested_token_use` に `on_behalf_of` を使う。RFC 8693 の `subject_token`、`actor_token`、`act` は出てこない。

MSAL の文書は、DPoP（RFC 9449）を公開クライアント向け、mTLS の結び付け（RFC 8705）をサービス間向けとする。代理の流れと、送信者の結び付けの関係は、記載がない。
