# F-G70. Loki は、compactor の retention_enabled を真にし、limits_config の retention_period を決めると、その期間を過ぎた記録を消す。既定では消さない

- 保存期間を適用するのは compactor である（"Retention in Grafana Loki is achieved through the Compactor."）。
- `retention_enabled` を真にしないと、compactor は表を圧縮するだけで、記録を消さない。既定では設定されない（"By default the `compactor.retention-enabled` flag is not set, so the logs sent to Loki live forever."）。
- 期間は `limits_config` の `retention_period` で決める。決めなければ `0s` で、無期限に残る。
- 保存期間を使うには、index の周期が 24h であることと、削除の要求の保存先（`delete_request_store`）が要る。
- 期間を変えても、すでに入った記録には遡って効かない。

文書は、ファイルの保存（filesystem）での動きに触れていない。このシステムの設定（`deploy/render.ts` の LOKI_CONFIG）で、7 日を過ぎた記録が実際に消えることは、確かめていない。
</details>
