# C-6. ISO/IEC/IEEE 29148:2018 は、要件をニーズと制約・条件を表す文と定義し、制約を設計や実装への外からの制限として区別する

要件（requirement）は、ニーズと、それに伴う制約と条件を、言い換えて表す文である。要件は、システムの構造の中の異なる水準にある（3.1.19）。制約（constraint）は、システムやその設計・実装・開発の過程に、外から課される制限である。解に強制的に課され、設計を限ったり変えたりしうる（3.1.7）。要件のトレーサビリティの表は、要件を上位の要件やニーズ、下位の実装に結び付ける（3.1.24）。

読んだのは、公開の見本（3 章まで）である。個々の要件の特性（5.2.5）、要件の言葉の基準（5.2.7）、要件の属性（5.2.8）は、本文を確かめていない。
