# F-G103. Floating UI の React の useFloating は、位置を style 属性に当てる

「`floatingStyles` is an object of positioning styles to apply to the floating element’s `style` prop.」とあり、例は `<div ref={refs.setFloating} style={floatingStyles}>` である。位置を決めない使い方（Interactions の節）では、`floatingStyles` を使わなくてよい。

Radix の Popover のページは、`--radix-popover-content-transform-origin` などの CSS の変数を示す。その変数を style 属性で書くかと、Floating UI を使うかは、ページに書かれておらず、確かめていない。
