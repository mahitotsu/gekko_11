# I-S1. 保険募集は、領域の判定基準を満たす

計画で決めた 3 点の確認のうち、2 点を監督指針の本文で確認できた。署名の扱いは、代筆の統制を確認できた（I-B1）。署名・押印の一般則は確認できなかった（I-B4）。意向確認と比較推奨の記録は確認できた（I-A2、I-B2）。申込書の事務点検と回付は確認できなかった（I-D2）。取消の仕組みは I-E1（要約のみ）。2 点以上を確認できたので、保険募集を主な題材にする。

<details>
<summary>補足</summary>

- 判定の基準と手順: 計画ファイルの Phase 0。
- 確認の範囲: 3 点（署名の主体、意向確認と比較推奨の記録、事務点検と回付）のうち、2 点を本文で確認。残る 1 点（事務点検と回付）は確認できなかった。
- 候補の訪問販売、携帯電話、不動産は、下調べの段階（本文未確認）に留まる。補助例としては、訪問販売のクーリング・オフ（起算日は書面の受領日。自治体の解説、二次）がある。
