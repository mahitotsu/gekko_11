# F-G58. webauthn4j 0.31 は Jackson 3 を使い、jackson-annotations 2.22 を求めるので、Spring Boot 3.5 の既定の版では動かない

webauthn4j 0.31 は、Jackson 3（パッケージ名 `tools.jackson`）で CBOR と JSON を読む。Jackson 3.2.3 は、annotations だけ 2 系の 2.22 を使う。Spring Boot 3.5.16 が管理する jackson-annotations はそれより古く、COSE の鍵を書き出すときに `NoSuchMethodError`（`JsonTypeInfo$Value.getWriteTypeIdForDefaultImpl`）で落ちた。

このリポジトリは、2 つの Java のサービスで、jackson-annotations だけを 2.22 に上げた。Jackson 2 系の databind は、そのまま動いた。
