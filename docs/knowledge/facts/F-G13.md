# F-G13. RFC 7519 は、aud が自分を含まない JWT を拒否するよう定める。iss、sub、aud、exp、typ は任意

JWT の基本仕様である。`iss`（発行者）、`sub`（主題）、`aud`（想定される受信者）、`exp`（有効期限）、`jti`（一意な識別子）などのクレームを定義する。`aud` がある場合、処理する側は、自分を識別する値が含まれていなければ、その JWT を拒否しなければならない（MUST、§4.1.3）。`exp` は、処理の時点がそれより前である必要がある（§4.1.4）。

ただし、これらのクレームは、この仕様では任意である。`typ` ヘッダーも任意で、使う場合は `JWT` が推奨され、実装は無視する（§5.1）。`alg` が `none` の JWT は、署名のない JWT を表し、それだけでは信頼の根拠にならない（§6、§11.1）。検証の手順（§7.2）は、`exp` や `aud` の検査を列挙しておらず、アプリケーションが行う。必須にするのは、RFC 9068 などの用途ごとの規則である。
