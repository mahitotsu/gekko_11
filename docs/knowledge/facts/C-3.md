# C-3. 国際監査基準は、独立した外部の情報源の証拠を、内部で作られた証拠より信頼できるとする。ただし IAASB は、この一般化が今は合わない可能性を検討した

ISA 505（外部確認）の 2 項は、ISA 500 の一般化を引く。証拠の信頼性は、入手元、性質、入手の状況に左右される。その上で、3 つを述べる。「独立した外部の情報源から得た証拠は、より信頼できる」。「監査人が直接入手した証拠は、間接的に、または推論で得た証拠より信頼できる」。「文書の形の証拠は、より信頼できる」。外部確認は、第三者（確認の相手）から監査人への直接の書面の回答と定義される（6 項(a)）。状況によっては、内部で作られた証拠より信頼できる（"depending on the circumstances"）。企業から独立した情報源から得た裏付け情報は、会計記録の証拠や経営者の陳述から得る保証を高めうる（3 項が引く ISA 500）。電子の確認では、暗号化、電子署名、ウェブサイトの真正性の確認で信頼性を高められる（A12）。

ただし、IAASB の 2019 年の議題資料は、ISA 500 の A31 項の記述が、今日の環境に合わないかもしれないと指摘した。対象は、「独立した外部の情報源から得ると、証拠の信頼性は高まる」「内部で作られた証拠は、内部統制が有効なら信頼性が高まる」といった記述である。2022 年の改訂案（ISA 500 改訂版）は、外部情報の検討を、情報源の信頼性など他の属性に向け直す。改訂後の最終文言は確認していない。「監査の基本中の基本」という表現の出典は見つからなかった。「突合」「証憑突合」の定義も、基準から確認できなかった。
