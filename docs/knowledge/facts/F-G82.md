# F-G82. Spring Security 6.5 のリソースサーバーは、DPoP のトークンと proof を確かめる。BearerTokenResolver が null を返すと、proof のない Bearer は断る

`oauth2ResourceServer` の JWT の設定だけで、`Authorization: DPoP` と `DPoP` の見出しを確かめる。別の鍵の proof は 401 になる。`Authorization: Bearer` で同じトークンを出すと、標準の部品は `cnf` を見ずに受け付けるので、`bearerTokenResolver` が null を返すようにして閉じる。`htu` は要求の URL で照らす。
