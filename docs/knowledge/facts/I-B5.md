# I-B5. 意向把握の帳票への顧客の署名は、法令上求められておらず、紛争への備えになる

意向把握は法律上の義務（保険業法 294 条の 2）である。しかし、意向把握に用いる帳票等への顧客の署名は、法令上も求められていない。意向把握シートに法定の様式はなく、パブリックコメントで、顧客の署名や押印を必ずしも求めるものではないという考え方が示された。署名があれば、後日の紛争への備えとして意味を持つ。比較推奨では、比較のために提示した商品名と、推奨に絞り込んだ合理的な理由を記録する（改正案の記述を含む）。署名を会社の規則で求めるかは、これらの出典に記述がなく、確認できなかった。

利用者から提供された解説には、意向確認書と申込書への自署が必須だという主張がある。意向確認書への自署が必須だという点は、上の出典では確認できなかった。
