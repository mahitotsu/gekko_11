# F-G71. Alloy の loki.source.kubernetes は、Kubernetes の API で Pod のコンテナーの記録を読む。ノードのファイルを読まず、DaemonSet なしで、1 つでクラスタ全体を集められる

- Kubernetes の API で、コンテナーの記録を読む。原文は "tails logs from Kubernetes containers using the Kubernetes API" である。ノードのファイルと、特権のコンテナーは要らない。
- DaemonSet は要らず、1 つでクラスタ全体を集められる（"one Alloy could collect logs for the whole cluster"）。
- 読む相手（targets）には、Pod の名前空間、名前、UID、コンテナーの名前の印が要る。`discovery.kubernetes` の出力には、既定でそろう。
- 認証の設定がなければ、Alloy の Pod の ServiceAccount で API を呼ぶ。要る権限は、この頁に書かれていない。
- 段階は general-availability である。悪い面として、`loki.source.file` より、kubelet の通信と CPU を多く使う。
