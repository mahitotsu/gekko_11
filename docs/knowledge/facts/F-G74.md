# F-G74. Spring Authorization Server 1.5.8 は、PKCE の値を持つトークンの要求を、証明書の確かめより先に公開クライアントとして扱う

既定のクライアント認証の変換は、5 つが次の順に並ぶ。JWT の assertion、client_secret_basic、client_secret_post、公開クライアント（PKCE）、X.509 の証明書である。最初に結果を返した変換が使われる。公開クライアントの変換は、`code_verifier` を持つ認可コードの要求を、クライアント認証 none として返す。そのため、mTLS の証明書を示していても、tls_client_auth で登録したクライアントは、none を許していないので断られる。

証明書の変換を先頭に置くと、証明書を示した要求は tls_client_auth として確かめられ、PKCE も確かめられた。証明書を示さない公開クライアント（顧客のアプリ）の要求は、これまでどおり公開クライアントとして通った。
