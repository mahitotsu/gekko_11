# I-A9. 生命保険の募集人は契約を媒介し、申込みを承諾するのは保険会社である

代理店の開示資料は、生命保険の募集人は契約を媒介し、契約締結の代理権を持たないと説明する。保険会社が申込みを承諾したときに、契約が成立すると説明する。保険業法の条文では確かめていない。承諾の前の査定は I-D1 にある。
