# F-G30. Keycloak 26.8 では、標準の token exchange は正式な対応だが、`act` を積む委任は preview で、既定では無効である

標準の token exchange（V2）は、正式に対応し、既定で有効である。古い token exchange（V1）は、preview で非推奨である。RFC 8693 の委任は、V2 で、Token Exchange Delegation の機能として preview で対応する。この機能は既定で無効で、`token-exchange-delegation` と `parameterized-scopes` の機能を有効にして使う（手引き）。

26.8.0 のリリースノートは、利用者の同意による委任で、出したトークンに、クライアントを行為者として示す `act` が入るとする。委任の対応の状態は preview である。成り代わりのセッションで出したトークンには、`act` が必ず入る。26.7.0 では、Token Exchange Delegation は experimental だった（見出しのみ確認）。

読んだのは、手引きの前半と、26.8.0 のリリースノートの本文である。手引きの委任の詳細（管理者の委任、クライアントの委任）は、本文を確かめていない。
