# F-G5. RFC 8705 は、トークンを証明書に結び付けるが、中継者の書き換えは防がない

mTLS は、OAuth クライアントの認証と、アクセストークンの証明書への結び付け（`cnf` の `x5t#S256`）を定める。トークンだけを盗んでも使えなくなる（§1、§3）。秘密鍵を持つ送信者が正規かどうかは区別しない。正規の中継者がリクエストの中身を書き換えることは、仕様の対象外である（本文に明示の記述はなく、読んだ内容からの推定）。TLS の終端を別の装置で行うときの証明書情報の受け渡しも、対象外である（§6.5）。
