# F-G76. Spring Authorization Server 1.5.8 の /connect/logout は、期限切れの ID トークンを拒まない。ID トークンを確かめられないと 400 を返し、この構成ではログインの画面へ送られる

ID トークンの期限は、交換の設定と別に、出してから 30 分である（`JwtGenerator`）。`/connect/logout` は、ID トークンが無効にされたか、使用開始の前かを確かめ、期限は確かめない。そのため、30 分を過ぎた画面でも、サインアウトできるはずである（読んだだけで、動かしていない）。

`id_token_hint` がない、または知らない値のとき、標準の応答は 400 のエラーである。このシステムでは、エラーの画面（`/error`）がログインを求めるので、`/login` へ送られる。そこでログインすると、戻り先がないので `/` へ送られ、入口が 404 を返す。

`errorResponseHandler` で応答を差し替えると、登録された戻り先へ戻せた。
