# F-G61. FastMCP 4.1 は、httpx ではなく httpx2 に依存し、HTTP の受け口で Host を確かめる

FastMCP 4.1.0 を入れると、`httpx` ではなく `httpx2`（pydantic による後継。API は同じ）が入る。`http_app` は、`allowed_hosts` などで、Host と Origin を確かめる（DNS rebinding の対策）。`get_http_headers` は、既定では `authorization` などを除くので、要るヘッダーは `include` で指定する。

このリポジトリの事務サービスは、`httpx2` で保険会社のシステムを呼び、受け口の Host を `insurer-mcp.<名前空間>.svc:9443` などに限る。
