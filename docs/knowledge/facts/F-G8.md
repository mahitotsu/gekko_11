# F-G8. WebAuthn で、取引内容を認証器の画面に出す仕組みは、読んだ範囲で確認できなかった

WebAuthn Level 3 の読んだ範囲に、取引内容を認証器の画面に表示する仕組みの記述はなかった。`challenge` はサーバーが生成する（§1.3.1）。認証情報は、その Relying Party に属する origin からしか使えない（§1）。仕様全体の約 2 割しか読んでおらず、「仕様にない」とは言えない。
