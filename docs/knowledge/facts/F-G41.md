# F-G41. node-oidc-provider は DPoP と mTLS（SAN の URI の照合を含む）に対応し、RFC 8693 の交換は組み込む側が拡張のグラントとして書く

node-oidc-provider（MIT ライセンス）は、RFC 9449 と RFC 8705 に対応する。クライアントの項目に `tls_client_auth_san_uri` がある。照合の処理は、組み込む側が書く。

RFC 8693 の交換は、`registerGrantType` で拡張のグラントとして登録する。補助の部品（`validateDpop`、`checkMtlsCert` など）は、交換の要求の proof や証明書に、出すトークンを結べる。ただし、補助の部品は「RFC 8693 を実装しない」とし、委任か成り代わりかの方針も決めない。
