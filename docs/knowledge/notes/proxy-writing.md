# 代筆の統制は、作成者の記録で上回る見込みがある

窓口では、自筆困難者の口頭の申込みの代筆に、複数の職員等の確認と記録を求める（I-B1）。DX では、AI が書いた内容に、`act` で AI が作成者であることが残る。本人の署名が、確認の証拠になる。

AI が書くことが常に代筆に当たるので、全ての申込に作成者の記録が残る。窓口の例外の統制を、全件に適用できる（推定）。

**前提:** 確認が、複数人の確認に相当するかは設計次第である。本人と、別経路の承認者（CIBA）の組み合わせが候補である。
