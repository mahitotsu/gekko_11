# 窓口の統制の型と、提案型で新しく生まれる危険

## 統制は 19 の型に整理できる
保険の募集の統制は、防ぐ対象ごとに分けると、19 の型になる。「防ぐ対象」は、窓口が実現したかった目的である。規則の文言や制度の趣旨から読み取れる。実際にどれだけ実現できていたかは、公開資料では分からないことが多い。「誰の目で」は、その統制を働かせる人である。

| 統制の型 | 防ぐ対象 | 誰の目で | 根拠 |
|---|---|---|---|
| 比較可能な商品の概要を示し、推奨の理由を説明する | 恣意的な誘導 | 営業員、顧客 | I-A2 |
| 手数料水準で商品を誘導しない。便宜供与を防ぐ | 営業員の利益相反 | 会社の監視 | I-A2、I-F1 |
| 契約概要と注意喚起情報の交付、口頭の説明、了知の確認 | 誤認 | 営業員、顧客 | I-C1 |
| 意向の把握と、意向確認書面の交付・保存 | 意向とのずれ | 営業員、顧客 | I-B2、I-G1 |
| 申込内容の確認と、申込書の写しの交付 | 申込内容の後出し変更 | 顧客 | I-A1 |
| 代筆は、複数の職員等が確認して記録する | 代筆の悪用 | 複数の職員 | I-B1 |
| 告知は、本人が書面で行う | 口頭の聞き違い、営業員の書き換え | 顧客本人 | I-B3 |
| 申込みの後に、会社が加入を査定する | 引受の誤り | 会社の査定担当 | I-D1 |
| 証券を代理店を介さずに顧客へ送り、顧客が照合する | 運ぶ途中の書き換え、無断の契約 | 顧客 | I-G2 |
| クーリング・オフ（補助） | 勧誘への不本意な承諾 | 顧客 | I-E1 |
| 営業員の教育、代理店の監査、不祥事件の届出 | 営業員の内部不正 | 会社、行政 | I-F1、I-F3 |
| 営業員の登録と、氏名・所属の明示 | 資格のない者の募集、立場の誤認 | 顧客、会社、行政 | I-B8 |
| 本人確認書類の原本による確認と、確認の記録 | なりすまし | 営業員、会社 | I-B6 |
| 被保険者の同意 | 無断で他人を被保険者にする契約 | 被保険者、会社 | I-B7 |
| 保険料の領収証と、会社への精算 | 保険料の着服 | 顧客、会社 | I-G3 |
| 訂正の記録と、差し替え・書き足しの防止（訂正印、契印・割印、大字。保険の申込書での運用は確認できず） | 署名後の書き換え | 事務担当、顧客 | I-A4 |
| 高齢者の募集の措置（親族の同席、別の担当者の電話確認など） | 判断の弱い人の不利益な申込み | 親族、別の担当者 | I-B9 |
| 面談の帳票と意向確認書面の保存 | 後日の追跡 | 会社、検査 | I-G1 |
| 所属する会社が、募集人の与えた損害を賠償する | 責任の所在 | 法 | I-H1 |

### 5 つの問いに分けると、統制の役割が見える
19 の型は、次の 5 つの問いに対応する。この分け方は、事実集の項目を整理した結果であり、資料にある分類ではない（推定）。

| 問い | 対応する型 |
|---|---|
| 営業員は正当か | 営業員の登録と氏名・所属の明示、教育、代理店の監査、不祥事件の届出 |
| 来た人は誰で、契約できる立場か | 本人確認書類の原本確認、被保険者の同意、加入の査定 |
| 提案は公正で、意向と合っているか | 推奨の理由の説明、誘導の禁止、契約概要と注意喚起情報の交付、意向の把握と確認、告知は本人が書面で、高齢者の募集の措置 |
| 申込内容は本人が確認したか | 申込内容の確認、申込書の写し、代筆の統制、保険料の領収証、訂正の記録と差し替えの防止 |
| 後で確かめ、追えるか | 証券の直送と照合、保存、会社の賠償責任。クーリング・オフは補助 |

## 提案型で新しく生まれる危険（窓口の場合）
提案型で新しく生まれる危険は、次の 6 つである。どれも、確認できた規定が間接的に防ぐが、直接防ぐ規定は読んだ範囲に見つからなかった（推定）。
- **推奨の偏り:** 営業員が、手数料などで特定の案に誘導する。理由の説明と監視で抑える（I-A2、I-F1）。
- **示した案と、申込書の食い違い:** 顧客が選んだ案と違う内容が、申込書に書かれる。申込内容の確認と、申込書の写しの交付が防ぐ（I-A1）。
- **無断の契約:** 顧客の意思なく申込書が作られる。署名、意向確認書面、クーリング・オフが歯止めになる（I-B2、I-E1）。
- **権限のない営業員による申込み:** 登録のない者や、扱えない商品の申込み。登録の有効性と範囲を、会社が確かめる必要がある。確かめる方法は確認できなかった（I-B8、I-D3）。
- **別人の本人確認の流用:** 確認記録と、申込書に署名した人が同じかを、点検する必要がある（想定）。
- **送り先のすり替え:** 営業員が別の住所を書く。本人確認書類で確かめた住所に送る必要がある（想定）。証券の郵送と返戻の有無で実在を確かめる方法はある（I-G2）。

## 提案型で新しく生まれる危険（電子の構成の場合）
2-7 の新しい危険（宛先違いの流用、本人の消失、中継者の書き換え、盗用）に加えて、提案型には次の危険がある。

| 新しい危険 | 対応 | 限界 |
|---|---|---|
| 示した案の書き換え、追加、削除 | 署名つきの提示、提示集合の識別子（P-1） | 署名の鍵を AI が持たないことが前提 |
| 選んだ案と違う申込の提出 | 選択と署名の結び付け（P-2） | 画面の信頼に依存する |
| 推奨の偏り | 全案の表示、指示の監査（P-3） | 意図は人でも AI でも見えない |
| 無断の契約 | 本人の署名、意向確認書面、取消（P-2、P-5） | 本人が読まずに署名する場合は防げない |
| 運ぶ途中の書き換え | 署名と、AI を経由しない直送と照合（P-2、P-8） | 顧客が受け取る経路が乗っ取られると成立しない |
| 事務センターでの、異なる内容の記録 | 署名済み申込の決定論的な取り込み、再計算による照合（P-16） | プログラムや保管庫に触れる内部者のリスクは残る |
| 取消の妨害 | AI から独立した取消の窓口（P-5） | 起算日の記録が前提 |
| AI への指示の混入 | 作成と承認の分離、権限の範囲 | 範囲内の誤りは防げない |
| 権限のない AI による申込み | 登録の有効性と範囲の検証（P-12、P-13） | 登録簿が正であることが前提 |
| 別人の本人確認の流用 | 確認済みの属性の主体と署名の鍵の結び付け（P-9） | 結び付けの設計が要る |
| 被保険者の同意の偽造 | 被保険者自身の署名（P-11） | 端末の不正な使用は防げない |
| 送り先のすり替え | 本人確認で確かめた経路だけに送る（P-14） | 経路の乗っ取りは防げない |
| 立場の偽り（AI が中立と名乗る） | 保険会社が署名した登録情報の表示（P-12） | 表示の遵守は監査に依る |

## 前提と、外れたときの影響
- **前提:** 金融庁の監督指針が、保険の募集の統制を代表している。外れたときの影響: 2 章の型と、3 章の代表例が変わる。
- **前提:** 5 つの問いの整理が、統制の役割を過不足なく表す。外れたときの影響: 設計文書の対応表の分け方が変わる。
- **前提:** 会社は、自社の営業員の登録を把握している（推定）。外れたときの影響: 営業員の確認の設計（[P-13](../decisions/P-13.md)）が変わる。
- **前提:** 営業員が記入した案を顧客が選ぶ運用は、実在する。外れたときの影響: 提案型の代表例が想定に留まる。
