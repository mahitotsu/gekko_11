# 設計の目標と非目標

**目標:**
- 保険の募集の統制を、防ぐ対象ごとに、同等以上に実現する。
- 営業員の役を AI が担い、多段呼び出しの途中にいても、保つ。
- 対象は、自分でアプリを操作できる顧客に限る。

**非目標:**
- 特定の製品や実装の提供。
- 法令や監督指針への適合の判断。
- 保険の引受の判断（査定の中身）。
- 自分でアプリを操作できない顧客の募集。対面の窓口で扱う。

## 「同等以上」の評価の言葉
判断の「詳しい理由」は、窓口の統制と比べた評価を、次の言葉で書く。評価は、窓口が実現したかった目的を、機械の手段がどれだけ確実に実現できるかで決める。
- **上回る:** 窓口が人の目や技能に頼る目的を、機械が毎回実現できる。
- **同等:** 同じ程度に実現できる。
- **下回る:** 実現しきれない部分が残る。
- **新しい統制:** 窓口に対応する統制がない。AI が間に入って生じた危険に対する統制である。

評価は推定を含む。窓口の実態を確かめられない統制は、評価しない（例: P-16）。
