# D-5. 確認画面は、署名する内容そのものから作り、AI の説明文からは作らない

## 理由
画面と署名の内容の一致を、保証しなければならない。WebAuthn 単体では、認証器の画面に取引内容を出す仕組みを確認できなかった（F-G8）

## 退けた案
AI の説明文を表示する。取引内容を表示しない。

## 影響
良い: すり替えが見える。悪い: アプリの実装に依存する。
