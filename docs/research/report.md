# 保険の募集は、理由の説明・意向の確認・申込書の写し・会社からの直送の 4 段で、選ぶことを本人のものにしている

営業員が複数案を示し、顧客が選んで署名する保険の募集について、DX 前の統制を整理した（金融庁の監督指針の本文などを確認）。

**この文書の読み手:** システムを発注する人、提案する人、作る人。保険の実務は知らなくてよい。読んだ後に、営業員が間に入る販売の統制を、防ぐ対象ごとに説明できる。用語は[用語集](glossary.md)、根拠は[事実集](findings.md)の項目番号（I-A1 など）にある。

## 要旨
- **調べたこと:** 営業員が複数案を示し、顧客が選んで署名する保険の募集。提案、申込書、本人と意向の確認、第三者の確認、取消、営業員の管理、事後の統制、責任の 8 区分。
- **選ぶことを本人のものにする統制は 4 段ある:** 推奨の理由の説明（I-A2）、意向確認書面（I-B2）、申込書の写し（I-A1）、証券の郵送と照合（I-G2）。この 4 段は、資料にない整理である（推定）。クーリング・オフ（I-E1）は、補助とする。
- **営業員の側と、申込みの正しさにも統制がある:** 手数料で誘導しない（I-A2）。登録と氏名の明示（I-B8）。本人確認書類の原本確認（I-B6）。被保険者の同意（I-B7）。
- **代筆は例外である:** 自筆が困難な人の口頭の申込みに限り、複数の職員等が確認して記録を残す（I-B1）。
- **信頼できる範囲:** 事務センターが営業員を確かめる方法、申込書の事務点検と回付は、確認できなかった（[5](#5-確認できなかったこと)）。

## 1. 保険の募集は、題材の条件を満たしたので選んだ
題材には、「営業員が記入済みの複数案を示す → 顧客が自分で選んで署名する → 営業員が事務担当に回付する」という流れが要る。銀行窓口の調査では、代筆の運用が公開資料から確認できず、「選ぶ」操作もなかった。

そこで、領域を決める基準を先に定めて、保険の募集を確かめた（I-S1）。制度の公開された資料から、署名の扱い（代筆）と、意向確認と比較推奨の記録を、金融庁の監督指針の本文で確認できた。申込書の事務点検と回付は確認できなかった。2 点以上を確認できたので、保険の募集を主な題材にする。

## 2. 統制は 19 の型に整理できる
保険の募集の統制は、防ぐ対象ごとに分けると、19 の型になる。「防ぐ対象」は、窓口が実現したかった目的である。規則の文言や制度の趣旨から読み取れる。実際にどれだけ実現できていたかは、公開資料では分からないことが多い。「誰の目で」は、その統制を働かせる人である。

| 統制の型 | 防ぐ対象 | 誰の目で | 根拠 |
|---|---|---|---|
| 比較可能な商品の概要を示し、推奨の理由を説明する | 恣意的な誘導 | 営業員、顧客 | I-A2 |
| 手数料水準で商品を誘導しない。便宜供与を防ぐ | 営業員の利益相反 | 会社の監視 | I-A2、I-F1 |
| 契約概要と注意喚起情報の交付、口頭の説明、了知の確認 | 誤認 | 営業員、顧客 | I-C1 |
| 意向の把握と、意向確認書面の交付・保存 | 意向とのずれ | 営業員、顧客 | I-B2、I-G1 |
| 申込内容の確認と、申込書の写しの交付 | 申込内容の後出し変更 | 顧客 | I-A1 |
| 代筆は、複数の職員等が確認して記録する | 代筆の悪用 | 複数の職員 | I-B1 |
| 告知は、本人が書面で行う | 口頭の聞き違い、営業員の書き換え | 顧客本人 | I-B3 |
| 申込みの後に、会社が加入の査定を行う | 引受の誤り | 会社の査定担当 | I-D1 |
| 証券を代理店を介さずに顧客へ送り、顧客が照合する | 運ぶ途中の書き換え、無断の契約 | 顧客 | I-G2 |
| クーリング・オフ（補助） | 勧誘への不本意な承諾 | 顧客 | I-E1 |
| 営業員の教育、代理店の監査、不祥事件の届出 | 営業員の内部不正 | 会社、行政 | I-F1、I-F3 |
| 営業員の登録と、氏名・所属の明示 | 資格のない者の募集、立場の誤認 | 顧客、会社、行政 | I-B8 |
| 本人確認書類の原本による確認と、確認の記録 | なりすまし | 営業員、会社 | I-B6 |
| 被保険者の同意 | 無断で他人を被保険者にする契約 | 被保険者、会社 | I-B7 |
| 保険料の領収証と、会社への精算 | 保険料の着服 | 顧客、会社 | I-G3 |
| 訂正の記録と、差し替え・書き足しの防止（訂正印、契印・割印、大字。保険の申込書での運用は確認できず） | 署名後の書き換え | 事務担当、顧客 | I-A4 |
| 高齢者の募集の措置（親族の同席、別の担当者の電話確認など） | 判断の弱い人の不利益な申込み | 親族、別の担当者 | I-B9 |
| 面談の帳票と意向確認書面の保存 | 後日の追跡 | 会社、検査 | I-G1 |
| 所属する会社が、募集人の与えた損害を賠償する | 責任の所在 | 法 | I-H1 |

### 2-1. 5 つの問いに分けると、統制の役割が見える
19 の型は、次の 5 つの問いに対応する。この分け方は、事実集の項目を整理した結果であり、資料にある分類ではない（推定）。

| 問い | 対応する型 |
|---|---|
| 営業員は正当か | 営業員の登録と氏名・所属の明示、教育、代理店の監査、不祥事件の届出 |
| 来た人は誰で、契約できる立場か | 本人確認書類の原本確認、被保険者の同意、加入の査定 |
| 提案は公正で、意向と合っているか | 推奨の理由の説明、誘導の禁止、契約概要と注意喚起情報の交付、意向の把握と確認、告知は本人が書面で、高齢者の募集の措置 |
| 申込内容は本人が確認したか | 申込内容の確認、申込書の写し、代筆の統制、保険料の領収証、訂正の記録と差し替えの防止 |
| 後で確かめ、追えるか | 証券の直送と照合、保存、会社の賠償責任。クーリング・オフは補助 |

## 3. 代表例は、自書型と提案型の 2 つの形で組み上げられる
流れの順序と各人の動きは、確認できた統制を並べた想定である。確認できた部分には根拠の番号を付け、確認できなかった部分は「想定」と書く。

### 3-1. 自書型では、顧客が書き、営業員が説明と確認を行う
顧客が自分で申込書に記入して署名する形である。

| 場面 | 誰が何をする | 働く統制 | 根拠 |
|---|---|---|---|
| 名乗り | 営業員が、氏名と所属を明らかにする | 氏名・所属の明示 | I-B8 |
| 本人確認 | 営業員が、本人確認書類の原本で確かめ、確認の記録を作る | 本人確認書類の確認と記録 | I-B6 |
| 相談 | 営業員が、顧客の意向を聞き取り、帳票に記録する | 意向の把握 | I-B2 |
| 説明 | 契約概要と注意喚起情報を渡し、重要事項を口頭で説明して、了知を確かめる | 説明と了知の確認 | I-C1 |
| 申込み | 顧客が記入して署名する。告知は、本人が書面で行う | 告知は本人が書面で | I-B3 |
| 確認 | 顧客が契約内容を確認し、申込書の写しを受け取る | 申込内容の確認、申込書の写し | I-A1 |
| 保険料 | 会社へ直接払い込むか、会社所定の領収証を受け取る | 領収証、会社への精算 | I-G3 |
| 会社へ | 営業員が申込書を会社に出す。確認の記録の添付と事務点検は想定 | （確認できず） | I-D2、I-B6 |
| 査定 | 会社が加入を査定し、承諾する | 加入の査定 | I-D1 |
| 申込み後 | 8 日以内なら、会社宛てに取り消せる（補助） | クーリング・オフ | I-E1 |
| 保存 | 意向確認書面などを保存する | 保存 | I-G1 |

### 3-2. 提案型では、営業員が複数案を示し、顧客が選ぶ
営業員が、記入済みの複数案を示す形である。顧客は 1 つを選んで署名し、営業員が事務担当に回付する。設計文書では、この営業員の役を機械が担う場合に、この形を対応づける。

| 場面 | 誰が何をする | 追加される統制 | 根拠 |
|---|---|---|---|
| 名乗り | 営業員が、氏名と所属を明らかにし、取り扱える保険会社の範囲を説明する | 氏名・所属の明示 | I-B8 |
| 本人確認 | 営業員が、本人確認書類の原本で確かめ、確認の記録を作る。誰のための契約か（被保険者、対象物）も確かめる | 本人確認、契約者の立場 | I-B6、I-B7 |
| 提示 | 営業員が、設計書や比較表で、顧客の意向に沿った比較可能な商品の概要を示す。この段階の書類に、顧客の署名は法令上求められない（会社の規則で求めることがある。想定） | 比較可能な商品の提示 | I-A2、I-B5 |
| 推奨 | 営業員が、特定の案を勧めるなら、その理由を客観的な基準で説明する。手数料の水準では誘導しない | 推奨の理由の説明、誘導の禁止 | I-A2 |
| 意向確認 | 顧客が案を選ぶ。意向確認書面で、意向と、案が意向に合う理由を確かめる。顧客が事実と違う記載を直せる。署名は法令上求められないが、後日の紛争への備えになる | 意向確認書面 | I-B2、I-B5 |
| 申込み | 顧客が申込書に署名する。告知は、本人が書面で行う。被保険者が別人なら、被保険者も同意の署名をする | 告知は本人が書面で、被保険者の同意 | I-B3、I-B7 |
| 写し | 顧客が申込内容を確認し、申込書の写しを受け取る | 申込内容の確認、申込書の写し | I-A1 |
| 回付 | 営業員が、意向確認書面、申込書、確認記録と書類の写し、被保険者の同意、登録番号を一式にして、事務担当に回す。一式の中身は想定 | （確認できず） | I-D2、I-D3 |
| 点検 | 事務担当が、本人、契約者の立場、営業員の登録、内容が署名したときのままかを確かめる。方法は想定 | （確認できず） | I-D3 |
| 直送 | 事務センターが、営業員を通さずに、本人確認済みの住所へ証券を郵送する。住所の確認は想定 | 証券の代理店を介さない交付 | I-G2 |
| 照合 | 顧客が写しと証券を見比べ、違えば会社へ直接連絡する | 顧客による照合 | I-G2 |

署名を置く段は、確認できた範囲では、申込書と告知である（I-B3、二次）。提示の書類と意向確認書面への署名は、法令上求められない。会社が証拠のために求めることはある（I-B5、想定）。署名の有無は、法令上の義務ではなく、証拠としての価値で決まる部分がある。

提案型で新しく生まれる危険は、次の 6 つである。どれも、確認できた規定が間接的に防ぐが、直接防ぐ規定は読んだ範囲に見つからなかった（推定）。
- **推奨の偏り:** 営業員が、手数料などで特定の案に誘導する。理由の説明と監視で抑える（I-A2、I-F1）。
- **示した案と、申込書の食い違い:** 顧客が選んだ案と違う内容が、申込書に書かれる。申込内容の確認と、申込書の写しの交付が防ぐ（I-A1）。
- **無断の契約:** 顧客の意思なく申込書が作られる。署名、意向確認書面、クーリング・オフが歯止めになる（I-B2、I-E1）。
- **権限のない営業員による申込み:** 登録のない者や、扱えない商品の申込み。登録の有効性と範囲を、会社が確かめる必要がある。確かめる方法は確認できなかった（I-B8、I-D3）。
- **別人の本人確認の流用:** 確認記録と、申込書に署名した人が同じかを、点検する必要がある（想定）。
- **送り先のすり替え:** 営業員が別の住所を書く。本人確認書類で確かめた住所に送る必要がある（想定）。証券の郵送と返戻の有無で実在を確かめる方法はある（I-G2）。

### 3-3. 代筆は、自筆困難者に限る例外である
自筆が困難な人が口頭で申し込み、職員等が代筆する場合、複数の職員等が確認して、その事実を記録に残す。社内規則でこの扱いを整える（I-B1）。代筆は、口頭の意思表示の範囲に限られる。

営業員が便宜のために記入することは、この規定の対象ではない（推定）。そのため、記入済みの案を示す運用の規定は、確認できなかった（I-A3）。

## 4. 統制の弱い点は、人の説明と事後の確認に依存する
弱い点は、窓口が意図した目的を、人の注意や技能に頼って実現していた点である。DX で何を補うかの手がかりになる。

### 4-1. 推奨の偏りは、人の説明と監視に依存する
推奨の理由を説明し、手数料で誘導しないという規定がある（I-A2）。しかし、営業員が実際に何を考えて案を選んだかは、説明からは分からない。監視と監査（I-F1）が頼りである（推定）。

### 4-2. 取消は、期間が限られ、対象外もある
クーリング・オフは、申込日か書面の受領日の遅いほうから 8 日以内である。保険期間が 1 年以内の契約などは対象外になる。会社宛てに出す必要があり、申込みを受けた代理店には出せない（I-E1、要約のみ）。

### 4-3. 申込内容の確認は、顧客が読むことに依存する
申込書の写しを渡しても、顧客が内容を読まなければ、食い違いは見つからない（推定）。証券が届いたときの見比べも同じである（I-G2）。確認を求める体制の規定はあるが、確認の質は、規定からは分からない（I-A1）。

### 4-4. 事務点検と回付は、読んだ範囲では見えない
営業員の側の統制は確認できたが、申込書を受け取った会社の側の事務点検、回付、相互牽制は確認できなかった（I-D2）。内容が署名したときのままかは、事務担当が目で点検し、技能に頼る（想定）。回付された申込みの営業員を、事務センターが確かめる方法も確認できなかった（I-D3）。登録の申請は所属保険会社が代理して行える（I-B8、要約のみ）ので、会社は自社の営業員の登録を把握している（推定）。

## 5. 確認できなかったこと
次の運用は、公開資料から確認できなかった。代表例では、想定として扱った。

- 営業員が申込書に記入する運用、申込書の様式、番号、訂正の扱い（I-A3）。
- 事務センターが、回付された申込みの営業員を確かめる方法（I-D3）。
- 確認記録と書類の写しを回す方法、証券の備考欄の確認済みの記載（I-B6）。
- 顧客が営業員の登録を照会する方法、登録が失効した後の扱い（I-B8）。
- 申込書への署名・押印・自署の一般則、代理人による申込み（I-B4）。
- 申込書の事務点検、事務への回付、相互牽制、役席の承認（I-D2）。
- 証券を代理店を介さずに交付する措置の、会社の営業員への適用と、事務センターが営業員を通さずに直接送る運用。無断の契約が証券の確認で見つかった事例（I-G2）。

次の項目は、**調べていない**。消費者契約法による取消、使用者責任との関係、保険業法の条文の本文、営業員の身分証、損害保険の被保険利益と対象物の所有者の確認（I-X1）。

確認する方法は、保険会社の事務規程、募集人向けの手引、実務経験者への聞き取りである。要約のみで確認した項目は、依拠する前に本文を読む。

## A. 前提と、外れたときの影響
- **前提:** 金融庁の監督指針が、保険の募集の統制を代表している。外れたときの影響: 2 章の型と、3 章の代表例が変わる。
- **前提:** 5 つの問いの整理が、統制の役割を過不足なく表す。外れたときの影響: 設計文書の対応表の分け方が変わる。
- **前提:** 会社は、自社の営業員の登録を把握している（推定）。外れたときの影響: 営業員の確認の設計（[dx-design.md](dx-design.md) の 3-14）が変わる。
- **前提:** 営業員が記入した案を顧客が選ぶ運用は、実在する。外れたときの影響: 提案型の代表例が想定に留まる。
